powershell-toolbox

A grab-bag of my PowerShell scripts, each one standalone

The PowerShell scripts I keep, whatever they happen to be for. Copy one out and it still runs. They assume your projects live in C:\Users\<you>\Projects, and every file they write goes there.

cd $HOME\Projects; git clone https://github.com/Real-Fruit-Snacks/powershell-toolbox; cd powershell-toolbox
winget install GitHub.cli; gh auth login
The current scripts wrap the GitHub CLI, so they see whatever your gh login sees, private repos included.

Scripts

The current set: your GitHub repos

I had a lot of repos, some dead, and no quick way to see them all at once. Get-Help .\<script>.ps1 -Full lists every parameter.

Get-RepoList.ps1

Lists every repo for an owner with its visibility and flags (archived, fork, template, empty), as a table, objects, CSV, JSON or Markdown.

Get-RepoDigest.ps1

Writes one Markdown file of repo metadata and READMEs, from GitHub and/or your projects folder (-Local), to upload to an LLM.

Invoke-RepoReview.ps1

Steps through repos one by one: delete, archive, keep or open in the browser. Logs every decision. Asks you to type the name before a delete; -WhatIf changes nothing.

.\Get-RepoList.ps1 -Owner Real-Fruit-Snacks -Format Markdown -OutFile repos.md   # -> Projects\repos.md
.\Get-RepoDigest.ps1 -GitHub -Local                                              # -> Projects\repos-digest.md
.\Invoke-RepoReview.ps1 -SortBy size -WhatIf                                     # log -> Projects\repo-review-<time>.log

# if the execution policy blocks a script
powershell -ExecutionPolicy Bypass -File .\Get-RepoList.ps1

House rules

Every script, every time

  • Standalone. A shared block of helpers is copied into each script, and a test keeps the copies identical.
  • Runs on Windows PowerShell 5.1 and PowerShell 7, ASCII only, so 5.1 never misreads a file.
  • Writes only under your projects folder, unless you pass an absolute path.
  • Anything destructive has -WhatIf and asks first.

Configuration

Environment

To set a different projects folder for good: [Environment]::SetEnvironmentVariable('RFS_PROJECTS', 'D:\code', 'User'), then open a new window.

VariableEffect
RFS_PROJECTSYour projects folder. Default $HOME\Projects. Relative -OutFile and -LogPath values land here.
RFS_THEMEdayshift for a light terminal; Nightshift is the default
NO_COLORPlain text, no colour

Tested on

  • Ubuntu 24.04 · PowerShell 7.4.6 · Pester 5.7.1 and 6.2.0, against a stub gh
  • Windows Server 2025 · Windows PowerShell 5.1 and PowerShell 7: the same suite in CI on every push
  • Not tested: macOS. It should behave like Linux; I haven't checked.

Known issues

  • Deleting needs the delete_repo scope on your gh token; Invoke-RepoReview.ps1 offers to add it.
  • Delete has no undo here. GitHub keeps most deleted repos restorable for 90 days, but not forks.
  • Get-RepoDigest.ps1 -GitHub makes two API calls per repo, so a third run within the hour can hit GitHub's rate limit at the 1,000-repo cap.
  • All three fetch at most 1,000 repos by default.
